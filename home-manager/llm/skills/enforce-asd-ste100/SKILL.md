# Enforce ASD STE100 Simplified Technical English Issue 9

## Apply the Standard

1. Preserve the technical meaning. Ask for clarification when a correction can change that meaning.
2. Identify the text type: procedural, descriptive, or safety instruction.
3. Read [Writing Rules][writing-rules] for every task.
4. Read [Procedures and Safety Instructions][procedures-and-safety-instructions] for procedures, notes, warnings, and cautions.
5. Read [Descriptive Writing][descriptive-writing] for descriptions and explanatory text.
6. Read [Dictionary Use][dictionary-use] before you approve vocabulary or report full compliance.
7. Read [Examples][examples] when you revise text or explain a rule.
8. Apply project terminology, publication specifications, style guides, and official directives together with this skill. Project directives govern spelling, abbreviations, formatting, and units of measurement where Issue 9 permits local rules.
9. Revise the text, and then complete the compliance review.

## Use the Controlled Dictionary Correctly

Do not infer that a familiar English word is approved. Approval depends on the word, its part of speech, its meaning, and its form.

Use an authorized copy of the Issue 9 dictionary when the task requires lexical validation. If the dictionary is not available, apply all writing rules but label the result as a writing rule review. Do not claim full ASD STE100 compliance.

Treat company approved technical nouns and technical verbs as permitted only when they satisfy the applicable Issue 9 categories and the project terminology source.

## Resolve Conflicts

Preserve quotations, legal text, identifiers, user interface labels, code, commands, and approved terminology when an exact value is necessary. Mark excluded text clearly when useful.

Do not replace a technical term only to make it shorter. Prefer technical accuracy and terminology consistency.

## Review Compliance

1. Check every sentence against the applicable reference files.
2. Count words with the Issue 9 counting rules.
3. Check each dictionary word against its approved part of speech, meaning, and form.
4. Check technical nouns and technical verbs against the project terminology source.
5. Correct each violation that does not change technical meaning.
6. Report unresolved items with the rule number and a concise reason.
7. State one of these outcomes:
    1. Full review complete. Use this outcome only when the controlled dictionary and project terminology were available.
    2. Writing rule review complete. Use this outcome when lexical validation was not possible.
