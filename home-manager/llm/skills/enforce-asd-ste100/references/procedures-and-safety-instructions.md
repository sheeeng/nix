# Procedures and Safety Instructions

## Procedural Writing

1. Rule 5.1: Use no more than 20 words in each sentence.
2. Rule 5.2: Put one instruction in each sentence. Combine actions only when they occur at the same time or form one result.
3. Rule 5.3: Write instructions in the imperative form.
4. Rule 5.4: Put a condition before the instruction when the reader must know the condition first.
5. Rule 5.5: Use a note only for information. Do not put an instruction in a note.

Give prerequisite information before the action. Put the result after the action when the reader must confirm it. Keep related steps in their necessary sequence.

## Safety Instructions

1. Rule 7.1: Identify the applicable safety level with the word that the governing safety specification requires, such as warning or caution.
2. Rule 7.2: Start with a clear and accurate command or condition.
3. Rule 7.3: Explain the risk or possible result.

Use this sequence unless the governing publication specification requires another sequence:

1. Safety level
2. Command or condition
3. Risk or possible result

Do not weaken a safety instruction with words such as please, should, might, or carefully when a direct command is necessary. Do not invent a hazard, consequence, safety level, or protective action.

## Review Questions

1. Does each step contain one instruction?
2. Does each instruction start with an imperative verb?
3. Does each necessary condition come first?
4. Does each sentence contain no more than 20 words?
5. Does each note contain information only?
6. Does each safety instruction identify its level, required action or condition, and consequence?
7. Does the step sequence preserve the technical and safety meaning?
