# Descriptive Writing

## Rules

1. Rule 6.1: Give information gradually. Present familiar or general information before new or detailed information.
2. Rule 6.2: Use key words and key phrases to give the text a logical structure.
3. Rule 6.3: Use no more than 25 words in each sentence.
4. Rule 6.4: Use paragraphs to group related information.
5. Rule 6.5: Put only one topic in each paragraph.
6. Rule 6.6: Use no more than six sentences in each paragraph.

## Information Order

Select an order that matches the subject. Common orders include general to specific, whole to part, cause to effect, and chronological sequence. Do not change the order without a technical reason.

Repeat a key word when repetition makes the topic clear. Do not replace a term with a synonym only to add variety.

Use active voice by default. Use passive voice only when the agent is unknown, unimportant, or obvious and the passive construction improves the technical focus.

## Review Questions

1. Does each sentence contain one topic and no more than 25 words?
2. Does each paragraph contain one topic and no more than six sentences?
3. Does the information move from known information to new information?
4. Do key words make the logical relationship clear?
5. Does each pronoun have one clear antecedent?
6. Does each passive construction satisfy Rule 3.6?
