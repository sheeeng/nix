## Words

1. Rule 1.1: Use only dictionary approved words, technical nouns, and technical verbs.
2. Rule 1.2: Use an approved word only as its specified part of speech.
3. Rule 1.3: Use an approved word only with its approved meaning.
4. Rule 1.4: Use only approved verb and adjective forms.
5. Rule 1.5: Use a word as a technical noun only when it belongs to an Issue 9 technical noun category.
6. Rule 1.6: Use a dictionary unapproved word only as a technical noun or as part of one.
7. Rule 1.7: Do not use a technical noun as a verb.
8. Rule 1.8: Use technical nouns approved for the company, industry, or subject field.
9. Rule 1.9: Select technical nouns that are short and easy to understand.
10. Rule 1.10: Do not use regional, slang, or jargon words as technical nouns.
11. Rule 1.11: Use one technical noun consistently for one item.
12. Rule 1.12: Use a verb as a technical verb only when it belongs to an Issue 9 technical verb category.
13. Rule 1.13: Do not use a technical verb as a noun.
14. Rule 1.14: Use American English spelling unless an official directive specifies a different spelling system.

Issue 9 provides 22 technical noun categories and four technical verb categories. Validate proposed terms against the complete standard and the applicable project glossary.

## Multiword Nouns

1. Rule 2.1: Use no more than three words in a multiword noun.
2. Rule 2.2: If an established technical noun has more than three words, write it in full at first use. Then use an approved shorter form or abbreviation consistently. Do not omit words arbitrarily.

Keep modifiers next to the noun that they modify. Make the relationship between the words unambiguous.

## Verbs

1. Rule 3.1: Use only the verb forms given in the dictionary.
2. Rule 3.2: Use the infinitive, imperative, simple present, simple past, simple future, and past participle where Issue 9 permits them.
3. Rule 3.3: Use a past participle as an adjective only in an approved construction.
4. Rule 3.4: Do not use auxiliary verbs to make complex verb constructions.
5. Rule 3.5: Use an ing form only as a technical noun or as a modifier in a technical noun.
6. Rule 3.6: Use active voice. In descriptive writing, use passive voice only when the agent is unknown, unimportant, or obvious.
7. Rule 3.7: Use an approved verb, not a noun or another part of speech, to express an action.

Prefer a simple tense. Name the agent when the agent gives useful information.

## Sentences

1. Rule 4.1: Write short, clear sentences. Put only one topic in each sentence.
2. Rule 4.2: Do not omit necessary words. Do not use contractions.
3. Rule 4.3: Use a vertical list for complex text.
4. Rule 4.4: Use approved connecting words and phrases to connect related sentences.
5. Rule 4.5: Use an article or demonstrative adjective when it makes the noun reference clear.

Use no more than 20 words in a procedural sentence and no more than 25 words in a descriptive sentence.

## Punctuation and Word Count

1. Rule 8.1: Use standard English punctuation marks, but do not use a semicolon.
2. Rule 8.2: Use a hyphen to connect words that are directly related.
3. Rule 8.3: Use parentheses only for permitted information, such as a cross reference, an abbreviation, or an alternative identifier. Do not put instructions in parentheses.
4. Rule 8.4: In a vertical list, treat a colon like a period for the word count. Count each list item as a separate sentence when applicable.
5. Rule 8.5: Count text inside one pair of parentheses as one word in its containing sentence.
6. Rule 8.6: Count an abbreviation, identifier, quoted group, number, or number with its unit as Issue 9 specifies. Validate unusual cases against the standard.
7. Rule 8.7: Count a hyphenated group as one word.

## Writing Practices

1. Rule 9.1: Change the sentence construction when direct word replacement produces an incorrect or unnatural sentence.
2. Rule 9.2: Use each approved word correctly.
3. Rule 9.3: Do not create an unapproved phrasal verb by combining words.
4. Rule 9.4: Use terminology and wording consistently.

## General Recommendations

1. General Recommendation 1: Use the conjunction that when it prevents ambiguity.
2. General Recommendation 2: Make each meaning of with clear. Rewrite the sentence when with hides the relationship.
3. General Recommendation 3: Make every pronoun reference clear.
4. General Recommendation 4: Put a clear noun after this when the reference can be ambiguous.
5. General Recommendation 5: Check false friends, especially when the writer or reader uses another first language.
6. General Recommendation 6: Avoid Latin abbreviations. Use approved English wording.
7. General Recommendation 7: Use inclusive language that is accurate, respectful, and unambiguous.
8. General Recommendation 8: Use possessive forms only when the relationship is clear. Rewrite ambiguous possessives.
