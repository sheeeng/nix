# Examples

## Copyright and Compliance Notice

These examples were written independently for this skill. They are not copied or adapted from *ASD STE100 Simplified Technical English, Issue 9*. Use them only to illustrate sentence structure and the cited rule. They do not establish that each word is approved in the Issue 9 dictionary.

Validate all vocabulary with an authorized Issue 9 dictionary and the applicable project terminology source before you claim full compliance. Do not add examples from the source publication to this file.

## Word Choice and Terminology

### Example 1: Use One Term for One Item

1. Pattern to correct: Remove the access cover. Put the panel on the workbench.
2. Original revision: Remove the access cover. Put the access cover on the workbench.
3. Applicable rule: Rule 1.11.

### Example 2: Do Not Use a Technical Noun as a Verb

1. Pattern to correct: Wrench the coupling loose.
2. Original revision: Use the wrench to loosen the coupling.
3. Applicable rule: Rule 1.7.

### Example 3: Do Not Use a Technical Verb as a Noun

1. Pattern to correct: Do a calibrate of the pressure sensor.
2. Original revision: Calibrate the pressure sensor.
3. Applicable rules: Rules 1.13 and 3.7.

### Example 4: Keep a Technical Noun Short

1. Pattern to correct: Forward equipment compartment illumination control selector.
2. Original revision: Equipment light selector.
3. Applicable rules: Rules 1.9 and 2.1.
4. Limitation: Use the revision only if the project terminology source approves it.

## Verbs and Voice

### Example 5: Use Active Voice

1. Pattern to correct: The status message is transmitted by the control unit.
2. Original revision: The control unit transmits the status message.
3. Applicable rule: Rule 3.6.

### Example 6: Use a Simple Verb Construction

1. Pattern to correct: The pump will have been operating for ten minutes.
2. Original revision: The pump will operate for ten minutes.
3. Applicable rules: Rules 3.2 and 3.4.

### Example 7: Express the Action with a Verb

1. Pattern to correct: Do an inspection of the cable clamp.
2. Original revision: Inspect the cable clamp.
3. Applicable rule: Rule 3.7.

### Example 8: Use Passive Voice Only When Permitted

1. Pattern to review: The protective coating is applied at the factory.
2. Permitted revision when the agent is unimportant: The protective coating is applied at the factory.
3. Preferred revision when the agent is important: The manufacturer applies the protective coating at the factory.
4. Applicable rule: Rule 3.6.

## Sentences and Lists

### Example 9: Do Not Omit Necessary Words

1. Pattern to correct: When ready, press the test switch.
2. Original revision: When the test unit is ready, press the test switch.
3. Applicable rule: Rule 4.2.

### Example 10: Do Not Use Contractions

1. Pattern to correct: The indicator does not illuminate because it isn't connected.
2. Original revision: The indicator does not illuminate because the power lead is not connected.
3. Applicable rule: Rule 4.2.
4. Note: The revision also removes an unclear pronoun.

### Example 11: Separate Topics

1. Pattern to correct: The battery supplies backup power, and the cooling fan starts when the enclosure temperature increases.
2. Original revision: The battery supplies backup power. The cooling fan starts when the enclosure temperature increases.
3. Applicable rule: Rule 4.1.

### Example 12: Use a Vertical List

1. Pattern to correct: Record the serial number, installation date, inspection result, and technician identifier.
2. Original revision:
   1. Record the serial number.
   2. Record the installation date.
   3. Record the inspection result.
   4. Record the technician identifier.
3. Applicable rule: Rule 4.3.

### Example 13: Make the Noun Reference Clear

1. Pattern to correct: Install seal on flange.
2. Original revision: Install the seal on the flange.
3. Applicable rule: Rule 4.5.

## Procedural Writing

### Example 14: Use One Instruction in Each Sentence

1. Pattern to correct: Open the drain valve and remove the filter cartridge.
2. Original revision: Open the drain valve. Remove the filter cartridge.
3. Applicable rule: Rule 5.2.

### Example 15: Keep Simultaneous Actions Together

1. Pattern to review: Hold the release lever and turn the adjustment knob clockwise.
2. Permitted revision: Hold the release lever while you turn the adjustment knob clockwise.
3. Applicable rule: Rule 5.2.

### Example 16: Use the Imperative Form

1. Pattern to correct: The technician should disconnect the data cable.
2. Original revision: Disconnect the data cable.
3. Applicable rule: Rule 5.3.

### Example 17: Put the Condition First

1. Pattern to correct: Install the locking pin if the alignment marks agree.
2. Original revision: If the alignment marks agree, install the locking pin.
3. Applicable rule: Rule 5.4.

### Example 18: Keep Instructions Out of Notes

1. Pattern to correct: Note: Replace the gasket before assembly.
2. Original revision: Replace the gasket before assembly.
3. Applicable rule: Rule 5.5.

## Descriptive Writing

### Example 19: Give General Information First

1. Pattern to correct: A ceramic sensing element measures the temperature. The monitor has three primary modules.
2. Original revision: The monitor has three primary modules. A ceramic sensing element in the sensor module measures the temperature.
3. Applicable rule: Rule 6.1.

### Example 20: Use One Topic in Each Paragraph

1. Pattern to correct: The charger controls battery current. The enclosure has two ventilation openings.
2. Original revision, paragraph 1: The charger controls battery current.
3. Original revision, paragraph 2: The enclosure has two ventilation openings.
4. Applicable rules: Rules 6.4 and 6.5.

### Example 21: Make Pronoun References Clear

1. Pattern to correct: Connect the receiver to the antenna after you inspect it.
2. Original revision: Inspect the antenna. Then, connect the receiver to the antenna.
3. Applicable recommendation: General Recommendation 3.

## Safety Instructions

### Example 22: Start with the Required Action

1. Pattern to correct: Hot fluid can cause an injury, so gloves should be worn.
2. Original revision: Wear thermal gloves. Hot fluid can cause an injury.
3. Applicable rules: Rules 7.2 and 7.3.
4. Limitation: Obtain the safety level and protective action from approved safety information.

### Example 23: Put the Safety Condition First

1. Pattern to correct: Do not touch the terminal because voltage is present.
2. Original revision: When voltage is present, do not touch the terminal. Contact with the terminal can cause an electric shock.
3. Applicable rules: Rules 7.2 and 7.3.
4. Limitation: Do not infer this hazard or consequence for an actual product.

## Punctuation and Word Count

### Example 24: Remove the Semicolon

1. Pattern to correct: The green light comes on; the controller is ready.
2. Original revision: The green light comes on. The controller is ready.
3. Applicable rule: Rule 8.1.

### Example 25: Keep Instructions Out of Parentheses

1. Pattern to correct: Remove the sensor (disconnect the lead first).
2. Original revision: Disconnect the lead. Remove the sensor.
3. Applicable rules: Rules 5.2 and 8.3.

### Example 26: Rewrite Instead of Replacing One Word

1. Pattern to correct: Perform a verification of the displayed value.
2. Original revision: Make sure that the displayed value is correct.
3. Applicable rules: Rules 9.1 and 9.2.
4. Limitation: Validate the revision with the controlled dictionary.
