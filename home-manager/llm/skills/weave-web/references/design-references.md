# Web Component Design References

Read these references when the component needs visual direction, animation,
canvas effects, or AI-native interface patterns.

implementation details, licenses, and dependencies.

## Normative Standards

Use [WCAG 2.2][wcag-22] for accessibility acceptance criteria. Use the
[HTML Standard][html-standard] for HTML behavior and semantics.
