# Exposed Superpowers Skills to All LLM Agents

Added automatic discovery for every directory skill under the pinned
[obra/superpowers skills directory][superpowers-skills].

The shared LLM settings now expose these skills to Codex and Claude Code.
OpenCode now consumes the same shared skill set and keeps its additional
OpenCode-specific skills.
