# Add the Hermes Agent Modules

Date: 2026-09-13T18:44:41Z.

## Summary

Added the Hermes Agent flake input to the configuration. The macOS host uses
the Home Manager module and the Linux hosts use the NixOS module. A sops-nix
template renders the `hermes/env` environment file from the `deepseek/api_key`
secret and the `telegram/bot_token` secret, so each value is stored once.

## Changes

- Added the `hermes-agent` flake input in `flake.nix`, with `nixpkgs` and
  `home-manager` set to follow the existing inputs.
- Imported `hermes-agent.nixosModules.default` in `hosts/linux/default.nix`
  and enabled the gateway, the system package, and the DeepSeek model. This
  applies to `fw13` and `p50`.
- Imported `hermes-agent.homeManagerModules.default` through
  `home-manager.sharedModules` in `hosts/darwin/default.nix` and enabled the
  command line, the gateway, and the DeepSeek model. The module applies to
  `aarch64-darwin` only, because the upstream flake does not declare
  `x86_64-darwin`.
- Added the `hermes/env` sops-nix template in `home-manager/sops.nix` for
  macOS and in `hosts/linux/sops.nix` for Linux. The template renders
  `DEEPSEEK_API_KEY` from `deepseek/api_key` and `TELEGRAM_BOT_TOKEN` from
  `telegram/bot_token`.
- Declared `deepseek/api_key` and `telegram/bot_token` from
  `secrets/common.yaml` in `hosts/linux/sops.nix`, so the Linux template can
  resolve the placeholders.
