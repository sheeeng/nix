# Add Linux Builders to macOS Hosts

Timestamp: 2026-10-30T08:09:44Z.

## Changes

Enable the shared Linux builder through
`determinateNix.nixosVmBasedLinuxBuilder` to preserve Determinate Nix.
The `nix.linux-builder` module requires `nix.enable`, which conflicts with
the existing Determinate module.

Use `pkgs.darwin.linux-builder-vz` for `aarch64-linux` on Apple Silicon.
Use `pkgs.darwin.linux-builder` for `x86_64-linux` on Intel.
Allocate eight cores and 8192 MiB of memory to each builder.
The Determinate module registers the SSH builder and disables its native
builder when this builder is enabled.
