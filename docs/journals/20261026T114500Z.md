# Repair the Darwin Certificate Bundle Build

Date: 2026-10-26T11:45:00Z.

## Summary

Removed the obsolete `emSign ECC Root CA - G3` certificate name from the shared
certificate blacklist.

## Cause

The current Mozilla certificate store no longer contains this certificate. The
`buildcatrust` utility rejects blacklist entries that do not match a certificate
in the store. This caused `nss-cacert-3.131.1` to fail and blocked the Darwin
system build.

## Verification

- Built `darwinConfigurations.TP95V9LWWL.pkgs.cacert` successfully.
- Ran `nix fmt -- modules/ca-certificates.nix` successfully.
- Ran `pre-commit run --files modules/ca-certificates.nix` successfully.
- Started a full Darwin system build. It continued to build unrelated
  dependencies after ten minutes and did not reproduce the certificate failure.
