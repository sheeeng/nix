# Remove the Stale VS Code Ripgrep Workaround

## Problem

VS Code 1.136.1 failed during the Nixpkgs patch phase. The package tried to
remove `rg` from `node_modules.asar.unpacked`, but the archive stored it in
`node_modules`.

The repository overlay changed the valid Nixpkgs path to the absent path. The
workaround was necessary for VS Code 1.129.1, but it is not valid for version
1.136.1.

## Change

Removed the stale `postPatch` path replacement. Kept the separate
`installPhase` workaround for nix-darwin issue 1315.

## Verification

Build the `fw13` NixOS system. Run the Nix flake checks and all pre-commit
hooks before activation.
