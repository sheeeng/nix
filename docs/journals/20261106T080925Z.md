# Clear tmux with Command-K

Timestamp: 2026-11-06T08:09:25Z.

Map Command-K to Ctrl-L in Alacritty, WezTerm, and the Ghostty configuration
used by cmux. Bind Ctrl-L in tmux to reset the active pane, send Ctrl-L to
the application, and clear the pane history. Other panes retain their history.
Ctrl-L also clears tmux scrollback when pressed directly.

An isolated tmux session confirmed that the binding command removes visible
output and scrollback and redraws a Bash prompt. Nix formatting and the full
pre-commit checks passed. Track this change in Beads issue `nix-y7b`.
The flake check was stopped while it waited for a pinned input download.

Apply the Nix configuration, then reload tmux with
`tmux source-file ~/.config/tmux/tmux.conf`. Restart the terminal if it does
not reload its key bindings automatically.
