# Keep the P50 Active

## Problem

The P50 could suspend after a lid event or a desktop power saving action. This behavior stopped background services until the system resumed.

## Change

Configured systemd logind to ignore lid events and idle actions. Disabled suspend, hibernation, hybrid sleep, and suspend then hibernate.

Manual shutdown and reboot remain available.

## Verification

Evaluate the P50 system configuration. Confirm that all lid actions and the idle action use `ignore`.

Confirm that every systemd sleep mode uses `false`.
