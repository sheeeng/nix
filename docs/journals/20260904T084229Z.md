# Remove the Remaining Zsh-Abbr Integration

## Problem

New Zsh sessions printed repeated `job-queue` timeout messages for
`zsh-abbr` initialization. The Antidote plugin entry had already been
removed, but the separate Home Manager module still enabled `zsh-abbr`.

## Change

Removed the `zsh-abbr` module import and its configuration file. Removed the
abbreviation autosuggestion strategy and the related environment variable.
Normal Zsh autosuggestions remain enabled.

## Verification

The repository search must return no active `zsh-abbr` configuration or
abbreviation-strategy references. Run the Nix flake check and all pre-commit
hooks before activation.
