# Enable Mullvad VPN on NixOS Hosts

Timestamp: 2026-10-04T17:00:00Z

Added `services.mullvad-vpn.enable = true;` to `hosts/linux/default.nix`.
Both active NixOS hosts, `fw13` and `p50`, import this configuration.
The Darwin host configurations do not use this NixOS option.

The Nix parser and `git diff --check` passed.
`nix flake check` passed for the current system.
Pre-commit could not initialize Renovate because its Node executable cannot
run on NixOS. Existing issue `nix-cjz` tracks this failure.
The user authorized a commit directly to `unstable`.
