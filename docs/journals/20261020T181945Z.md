# Scope the Intel Darwin Nixpkgs Pin to Host C02ZV797MD6R

Date: 2026-10-20T18:19:45Z.

## Summary

Scoped the `nixpkgs-26.05-darwin` pin to host `C02ZV797MD6R` only.
Removed architecture-wide pinning behavior that had expanded the change to
all `x86_64-darwin` evaluation paths.

## Changes

- Updated `flake.nix` input URL to
  `github:NixOS/nixpkgs/nixpkgs-26.05-darwin`.
- Kept `enableNixpkgsReleaseCheck = false` only for hostname
  `C02ZV797MD6R`.
- Replaced `flake-utils.lib.eachDefaultSystem` with an explicit
  `eachSystem` list that excludes `x86_64-darwin`, so generic tool outputs do
  not force architecture-wide pinning.
- Reverted the shared overlay `unstable` package set to use the main
  `nixpkgs` input instead of conditionally importing the 26.05 Darwin pin.
