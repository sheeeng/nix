# Restore the P50 GNOME Theme

## Problem

The P50 used GNOME after the Plasma desktop was removed. The host did not declare GNOME interface settings.

The missing settings caused the cursor and desktop theme to use stale or unavailable values from the previous session.

## Change

Added Home Manager dconf settings for the GNOME interface. The settings select the Adwaita cursor, icons, GTK theme, and fonts.

## Verification

Evaluated the P50 Home Manager dconf settings. The evaluation returned the declared Adwaita values.
