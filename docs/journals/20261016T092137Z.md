# Work Around Atuin Darwin Build Failure

Date: 2026-10-16T09:21:37Z.

Add an Atuin overlay that sets `NOSYSBASHRC=1` during checks.
This prevents the unsandboxed Darwin end-to-end test from sourcing the host
Bash configuration, which replaces the test `PATH`.

Track the upstream defect in [NixOS/nixpkgs issue 573527][nixpkgs-573527].
Remove the overlay after the Nixpkgs fix is available in the flake input.

[nixpkgs-573527]: https://github.com/NixOS/nixpkgs/issues/573527
