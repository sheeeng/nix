# Add Ghostty Theme File for Rex Beta

Timestamp: 2026-11-24T12:07:00Z.

Rex Beta has no declarative theme option and does not migrate Ghostty colors.
Its Settings > Theme > Import button reads a Ghostty theme file.

Write the existing Ghostty background, foreground, and palette values to
`~/.config/ghostty/themes/leonard` in `home-manager/programs/ghostty.nix`.
After activation, import that file in Rex Beta to match the Ghostty theme.
Rex Beta keeps the imported theme in application state, so this step is manual.
