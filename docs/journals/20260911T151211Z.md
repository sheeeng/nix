# Configure Scoped Dolt Identities

Date: 2026-09-11

## Summary

Configured Dolt identities through Home Manager without changing the managed
global Git identity. The global Dolt configuration uses the private identity,
while the embedded Beads database and its Git transport cache use the GitHub
noreply identity.

## Changes

- Added the Dolt package and managed `~/.dolt/config_global.json`.
- Added a Home Manager activation step for the local embedded Dolt database.
- Extended the existing Git conditional includes to cover the nested bare Git
  cache that transports `refs/dolt/data`.
- Patched embedded Beads commits to use the GitHub noreply identity.
- Replaced the Home Manager backup shell fragment with an executable backup
  command.

## Verification

- Applied the nix-darwin configuration.
- Confirmed the global and local Dolt JSON files contain their intended
  identities.
- Confirmed the nested Git cache resolves to the GitHub noreply identity.
- Force-pushed the repaired Dolt history.
- Completed a normal `bd dolt pull` and `bd dolt push`.
- Confirmed all remote `refs/dolt/data` Git commits use the GitHub noreply
  identity.
