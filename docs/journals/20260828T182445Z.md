### 2. Legacy `nix-shell` support (`shell.nix`)

The default argument `pkgs ? import <nixpkgs> { }` neither enabled
unfree packages nor applied the modifications overlay. A clean
`nix-shell` invocation would reject Terraform (unfree license) and
would not use the canonical derivation.

Fix: expanded the default to set `config.allowUnfree = true` and
inline the Terraform overlay:

```nix
pkgs ? import <nixpkgs> {
  config.allowUnfree = true;
  overlays = [
    (final: _prev: {
      terraform = final.callPackage ./pkgs/terraform.nix { };
    })
  ];
},
```

Commit: `fix(shell): apply overlay for nix-shell`
