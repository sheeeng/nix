# Replaced GNOME with Plasma on fw13

The `fw13` host now uses KDE Plasma 6 and SDDM on Wayland. The Plasma module enables KDE Wallet and its PAM integration.

Hyprland and Sway are available as optional login sessions. Hyprland uses the Universal Wayland Session Manager integration.

Both Linux hosts enable IBus with Mozc, Pinyin, and UniEmoji.

Kitty, Warp, and WezTerm are available on all hosts. Ghostty and Konsole are available on Linux hosts because Nixpkgs does not support them on Darwin.

The host now uses the OpenSSH agent. The removed GNOME service no longer loads SSH keys through GNOME Keyring.
