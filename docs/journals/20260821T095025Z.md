# Use the macOS Keychain for SSH Keys

The Darwin profile used GnuPG's SSH agent for regular OpenSSH keys. The shell
therefore pointed `SSH_AUTH_SOCK` at the GnuPG agent, which prompted for the
`id_ed25519` passphrase repeatedly.

The SSH configuration now enables Apple's `UseKeychain` behavior on Darwin.
GnuPG SSH support is disabled on Darwin so the native macOS SSH agent handles
the key. Linux hosts retain GnuPG SSH support.

After the next system activation, add the key to Apple's keychain once with
`ssh-add -K ~/.ssh/id_ed25519`. New terminal sessions then
use the native agent and keychain entry.
