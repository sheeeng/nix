# Revert UseKeychain SSH Setting

Date: 2026-09-01T21:28:09Z

Reverted the `UseKeychain` SSH setting added in the earlier commit today.
`UseKeychain` is an Apple-specific option introduced in macOS Sierra via
Apple's OpenSSH patch. Nix installs standard OpenSSH, which does not include
that patch and rejects the option with "Bad configuration option: usekeychain".
The error breaks all SSH remote operations, including git push and git fetch.

Removed the setting from `home-manager/programs/ssh-darwin.nix`. The
`AddKeysToAgent yes` setting in the `Host *` block handles passphrase caching
via the SSH agent on modern macOS without requiring the Apple-specific option.

Reference: <https://developer.apple.com/library/archive/technotes/tn2449/_index.html>
