# Fix OpenLogi macOS Packaging

Date: 2026-10-20T12:35:15Z.

## Change

Override OpenLogi for Darwin hosts.
Use the `osx` bundle format instead of the default DMG output.
Remove the metadata fields that `cargo-bundle` 0.9 does not support.

## Reason

The default bundle command tried to create a DMG with `hdiutil`.
The Nix sandbox does not provide this Apple system utility.

## Verification

Build `darwinConfigurations.TP95V9LWWL.pkgs.openlogi`.
The build completed after the override.
