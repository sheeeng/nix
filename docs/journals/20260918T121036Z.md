# Fix Dependency Automation Failures

Removed the Renovate custom manager for `fetchFromGitHub` sources. The hosted
Renovate service cannot run the repository hash update command, and the
scheduled `Update Nix Fetchgit Dependencies` workflow already owns these
updates.

Removed the pre-commit environment cache from the Determinate workflow. Cached
pre-commit environments can contain executable paths from a Nix store that is
not present on a later runner.

Formatted the Nix file reported by the pull request workflow.
