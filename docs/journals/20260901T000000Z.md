# Use the macOS SSH Keychain

Date: 2026-09-01T00:00:00Z

Removed the forced GPG SSH-agent socket from the Darwin host. GPG SSH support
is disabled, so that socket could not cache `id_ed25519` for Visual Studio
Code. Enabled the Darwin-only `UseKeychain` SSH setting so macOS can retain the
key after the first passphrase prompt.
