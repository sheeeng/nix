# Extend the Weave Web References and Add Design Skills

## Date

2026-09-07T18:16:26Z

## Change

Expanded the [Web Component Design References][design-references] for the
`weave-web` skill. The table now lists UI SFX, BotLab, Libraries.dev,
KitBitz, Tool's Beach, Sylva, and p5.brush with their websites and source
repositories where sources exist.

Added the public KitBitz MCP server to [mcp.nix][mcp-nix]. The server uses
the documented Streamable HTTP endpoint and requires no authentication.

Added two local skills from upstream sources:

1. `design-mascot-logo` duplicates [IP as Logo][ip-as-logo] at commit
   `acb834c717bcd0a487c49732d08397ba280d690b`.
2. `design-mengto` wraps the [MengTo Skills][mengto-skills] collection at
   commit `321c769739b823de5eb94eb3a52aa1974fe783a2`.

The MengTo vendored snapshot keeps instructional and supporting text files.
It omits large preview images, videos, fonts, and other demo media. The
formatter and linter configuration excludes the vendored snapshot so that
its upstream formatting stays unchanged.

## Validation

- The skill validator passed for `weave-web`, `design-mascot-logo`, and
  `design-mengto`.
- `pre-commit run --all-files` passed all hooks for the tracked files.
- All non-network hooks passed for the new files.
- The KitBitz MCP endpoint matches the endpoint in the public documentation.
- External link checking requires network access, which the sandbox does
  not provide.
