# Fix Python 3.14 debugpy Test Failure

Timestamp: 2026-10-12T09:55:36Z

The Visual Studio Code Python extension requires `python3.pkgs.debugpy`.
Its debugpy 1.8.22 integration test suite fails on Darwin with Python 3.14.
The failures include conditional breakpoints, return-value evaluation, and the LLDB command test.

Disable checks only for the Darwin Python 3.14 debugpy package.
The package builds and imports successfully with checks disabled.

Track this change in Beads issue `nix-74z`.
