# Reuse the SSH Passphrase Across Shell Sessions

## Date

2026-08-26T07:09:23Z

## Problem

The SSH key loader could retrieve a passphrase from the login keyring.
It did not provide a command to store the passphrase for the first time.

Shell modules also configured the GCR agent socket separately.
This arrangement omitted Bash and could produce different shell environments.

## Change

Added `ssh-passphrase-store` to the shared Linux Home Manager configuration.
The command stores the passphrase in the login keyring and reloads the SSH key.

Enabled the Home Manager `sshAuthSock` integration for Bash, Fish, Nushell,
and Zsh. All shells now use the GCR SSH agent socket.

No host configuration changed.

## Use

Apply the Home Manager configuration. Then run this command once:

```shell
ssh-passphrase-store
```

Enter the SSH key passphrase when `secret-tool` requests it. The login keyring
supplies the passphrase to the SSH key loader in later graphical sessions.
