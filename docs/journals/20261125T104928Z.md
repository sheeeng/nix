# Disable Hosted OpenCode Providers

Date: 2026-11-25T10:49:28Z.

## Changes

Add the `opencode` and `opencode-go` providers to `disabled_providers`
in the OpenCode Home Manager module. Set `share` to `"disabled"` to turn
off `/share` completely. OpenCode used its own hosted models to generate
session titles. The maintainers state that this stopped, but the hosted
models stay disabled by default. See
https://github.com/anomalyco/opencode/issues/10416.

`virtualenv` package lacks the `packaging` module. The commit used
