# Fix Pre-Commit Environment Cache Restore

Date: 2026-09-21T06:58:45Z

## Problem

The `gitleaks` fix in the previous task removed one symptom. The same failure
then appeared on the other two `language: golang` hooks:

```text
[Errno 2] No such file or directory:
'~/.cache/pre-commit/repoeagh7i3p/golangenv-1.23.1/bin/keep-sorted'
[Errno 2] No such file or directory:
'~/.cache/pre-commit/reposvdx1kj5/golangenv-system/bin/yamlfmt'
```

The cause is the cache, not the hooks. The job log shows three facts:

1. The restore missed the primary key and matched the `restore-keys` prefix
   `pre-commit-Linux-`. That prefix restores hook environments that belong to
   a different hook configuration.
2. The `pre-commit install-hooks` command reinstalled the Python and Node
   environments but skipped the Go environments.
3. Pre-commit rebuilds an environment only when the `.install_state_v2` marker
   is absent. The stale cache contained the marker without the executable.

## Changes

`.github/workflows/run-pre-commit-via-nix.yaml`:

- Remove `restore-keys`. Restore the cache only on an exact key match.
- Key the cache on `.pre-commit-config.yaml` alone. The Nix store supplies the
  tools and has its own cache, so `flake.lock` must not churn this key.
- Add a repair step that removes any hook environment whose `bin` directory
  holds no file. Pre-commit then rebuilds that environment.

The save step still runs only after the hooks succeed, so a canceled or failed
run cannot publish a partial cache.

## Validation

```shell
pre-commit run --files .github/workflows/run-pre-commit-via-nix.yaml
```

The `actionlint` hook passed, which also runs `shellcheck` on the `run` block.

The repair loop was tested against a synthetic cache that held one complete Go
environment, one Go environment with a marker but no `bin` directory, and one
complete Python environment. The loop removed only the incomplete environment.

## Notes

The `gitleaks-system` hook from the previous task is retained. It removes one
Go build from every run. Its version now comes from nixpkgs rather than the
pinned hook revision, so the two can drift.
