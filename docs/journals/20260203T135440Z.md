# `lib.getExe` vs `lib.getExe'` in Nix

The `'` (prime) denotes a variant of the base function.

| Function      | Purpose                                | Example                                              |
| ------------- | -------------------------------------- | ---------------------------------------------------- |
| `lib.getExe`  | Get the main executable from a package | `lib.getExe pkgs.bat` → `.../bin/bat`                |
| `lib.getExe'` | Get a specific executable by name      | `lib.getExe' pkgs.findutils "find"` → `.../bin/find` |

Use `lib.getExe'` when a package contains multiple executables (e.g., `findutils` has `find`, `xargs`, `locate`).
