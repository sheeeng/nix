# Add the Weave Web Skill

## Date

2026-09-07T17:03:55Z

## Change

Added the `weave-web` skill for standards-based web component implementation.
The skill treats responsive mobile and desktop behavior as equal acceptance
conditions.

The skill requires semantic HTML, accessible input, intrinsic CSS, progressive
enhancement, state coverage, and visual verification. It also requires
`animate-kinetics` and `animate-text` when their motion scopes apply.

The `references` directory contains the design and standards sources. The
design references include [Rare UI][rare-ui], [Canvas UI][canvas-ui],
[Transitions.dev][transitions-dev], and [Beautiful UI][beautiful-ui]. WCAG 2.2
and the HTML Standard provide normative guidance.

## Exposure

The shared LLM settings discover `weave-web` from its directory. They expose
the skill to Codex, Claude Code, OpenCode, and GitHub Copilot CLI.
