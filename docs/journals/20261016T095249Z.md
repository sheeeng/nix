# Separate Nix Evaluation from Full Builds

Date: 2026-10-16T09:52:49Z.

## Changes

Pull requests and default branch pushes evaluate the macOS system derivation.
The evaluation job has a 15-minute timeout.
Full macOS builds run nightly at 02:17 UTC and on manual workflow runs.
Linux hosts retain full builds for all workflow events.

Build the Darwin system directly from the locked flake.
Use two concurrent jobs with two cores per job.
Remove feature branch push triggers to avoid duplicate pull request builds.
Remove the separate unpinned Coreutils build and use portable directory creation.
Keep GitHub App authentication and explicit job permissions.
