# Restore Linux Builder Bootstrap

Timestamp: 2026-10-30T11:32:24Z.

## Change

Remove the custom NixOS virtual machine configuration from the macOS Linux
builder. The custom settings generated a unique `aarch64-linux` virtual machine
closure. The macOS host cannot build that closure before the builder starts.

The default `linux-builder-vz` package provides a cached bootstrap closure.
Keep the Apple Silicon package selection and the supported feature declaration.

## Verification

The default `create-builder` derivation built successfully. The focused Darwin
system build resolved the Linux builder closure from the binary cache instead
of attempting a local `aarch64-linux` build. The complete system build continued
to download unrelated Darwin and Home Manager dependencies after ten minutes.
