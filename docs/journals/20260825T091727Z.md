# Stop Repeated SSH Passphrase Prompts

## Date

2026-08-25T09:17:27Z

## Problem

Nushell used the GnuPG SSH socket. The login service loaded the OpenSSH key
into the GCR SSH agent instead.

Git could not find the loaded key. Each new SSH connection requested the key
passphrase again.

## Change

Disabled GnuPG SSH support in the [GnuPG module][gnupg-module]. GnuPG continues
to handle signing operations.

The GCR SSH agent now remains the only configured SSH agent on Linux hosts.

## Verification

Evaluated the P50 Home Manager configuration. The GnuPG SSH support option now
has the value `false`.

[gnupg-module]: ../../home-manager/programs/gnupg/default.nix
