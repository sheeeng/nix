# Load the SSH Key from KWallet on Plasma

## Problem

The `p50` host started an OpenSSH agent for each login session. The agent did not load the private key at session start.

The shared Home Manager service used GNOME GCR. The `p50` host removed that incompatible service without adding a Plasma replacement.

As a result, the first Git SSH connection after login requested the key passphrase. OpenSSH then cached the key for that session.

## Change

Add a Home Manager user service for the `p50` host. The service starts with the Plasma graphical session and runs `ssh-add`.

The service uses KSSHAskPass for the passphrase dialog. KSSHAskPass can retrieve the saved passphrase from KWallet after the initial setup.

## Verification

Evaluate the generated Home Manager service. Confirm these values:

1. `SSH_AUTH_SOCK` points to `%t/ssh-agent`.
2. `SSH_ASKPASS` points to KSSHAskPass.
3. The service requires `ssh-agent.service`.
4. The service starts with `graphical-session.target`.

After activation, sign out and sign in. Store the passphrase in KWallet when KSSHAskPass requests it.
