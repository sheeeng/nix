# Make Pi Authentication File Writable

Timestamp: 2026-11-01T18:41:29Z.

## Change

Remove the `home.file` entry for `~/.pi/agent/auth.json`. That entry created a
read-only symlink into the Nix store, so Pi could not save GitHub Copilot OAuth
credentials.

Seed the DeepSeek credential from a Nix store template with a Home Manager
activation entry. The activation entry replaces an old symlink with a mode
`0600` regular file only when the file is missing. Pi then owns the file and can
write additional credentials.

## Verification

`nix fmt` formatted the changed Nix file. `nix-instantiate --parse` accepted the
file. `nix flake check` completed successfully. The user requested that
`pre-commit run --all-files` be skipped.
