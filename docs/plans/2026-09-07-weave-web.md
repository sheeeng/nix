# Weave Web Skill Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Create and validate a framework-neutral skill for responsive web component implementation.

**Architecture:** Keep the workflow in `SKILL.md`. Put design sources and standards in one disclosed reference file. Add only the user interface metadata that Codex needs for discovery.

**Tech Stack:** Markdown, YAML, Codex skill validation, pre-commit, and Nix flakes.

---

## Task 1: Test Baseline Behavior

**Files:**

- Create: `/tmp/weave-web-baseline.md`

### Step 1: Define a Pressure Scenario

Ask an agent to implement a visual web component under a deadline without
loading `weave-web`. Require it to state its implementation and verification
choices.

### Step 2: Run the Scenario

Capture omissions that affect mobile layouts, desktop layouts, accessibility,
motion preferences, fallbacks, or verification.

## Task 3: Test Skill Behavior

**Files:**

- Create: `/tmp/weave-web-with-skill.md`

### Step 1: Run the Baseline Scenario With the Skill

Require the test agent to read and apply `weave-web`.

### Step 2: Compare the Result With the Acceptance Conditions

Revise only instructions that do not produce the required behavior. Repeat
the test after each revision.
